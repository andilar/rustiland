# hello_ferris

Kleines Rust-Einstiegsbeispiel: `ferris-says` gibt „Hello fellow Rustaceans!“ mit Ferris in der Konsole aus. Demonstriert Cargo-Abhängigkeiten sowie gepufferte Ausgabe über `stdout` und `BufWriter`.

## Voraussetzungen

Rust und Cargo; keine besondere Hardware oder Betriebssystemintegration.

## Starten

Vom Repository-Stamm aus:

```sh
cd learning/hello_ferris
cargo run
```

## Stand

Überschaubares Lernbeispiel mit festem Begrüßungstext. Bisher keine eigenen Tests.
